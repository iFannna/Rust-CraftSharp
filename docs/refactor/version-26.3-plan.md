## 1. 范围

- 本轮只把物品、方块、实体贴图，默认皮肤，以及 3D 实体的几何、逐面 UV、动画、姿态常数升级到 Java 26.3。
- 不做：HUD 与容器 GUI、字体、物品栏布局、音效、语言，版本切换与资源下载，启动器，新增实体。
- 不变量：模型仍是 y 向上、正面 +z 的右手系；渲染接口与 HUD 行为不变；项目自有数据（`player/uv/*.json`、`item/data`、`block/data`、barrier 引用）不丢。

## 1. 现状与差异（已实测）

- 26.3 正式版发布于 2026-09-15，本机未安装。客户端 jar 已从 Mojang 清单取得，41MB。
- 对照 1.20.4 jar：
  - 物品贴图 587 → 831，新增 271、删除 27、451 张内容变化。项目实际存放在 `textures/item/`，当前 831 张。
  - 方块贴图 1039 → 1405，新增 369、删除 3、817 张内容变化。项目存放在 `textures/block/`，当前 1300 张 PNG。
  - 实体贴图 500 → 759，新增 393、删除 134、290 张内容变化。现有五个实体在 26.3 的路径全部保留，尺寸不变；龙眼图未变。
  - 默认皮肤 18 张名称不变，部分内容更新（steve 已变，alex 未变）。
  - 范围内贴图解压后约 1.0MB，体积不是问题。
- GUI 与字体也有大量变化，按约定留到后面，本轮不动。
- 最新官方基岩几何与现有玩家的、苦力怕、铁傀儡模型按 z 取反映射仍 ALL MATCH，说明这三个几何大概率没变；村民、末影龙与全部姿态常数仍需要 26.3 的 Java 源码确认。

## 2. 模型源码怎么拿

- 现有 `reference/java` 的公开反编译仓库停在 2023 年，不能用于 26.3；26.3 的版本 JSON 也不再提供 client mappings。
- 采用 Bram1903/MinecraftSourcesGenerator 本地生成：JDK 17 运行 Gradle，构建自动使用 Java 25 toolchain，直接产出 26.3 源码，并支持 1.20.4 到 26.3 的 diff。
- 生成的源码不提交仓库，放在本地忽略目录；仓库只更新烘焙后的 JSON 与来源说明。
- 备用方案：若生成失败，先用最新官方基岩几何加现有 Java 常数，只换贴图，并在文档中标明村民、末影龙与姿态的风险。不首选。

## 4. 风险

- 生成源码需要访问 Mojang 与多个 Maven 源，可能受网络影响；失败则走备用方案。
- 物品与方块目录是项目自有结构且有独有文件，不能整目录覆盖，必须按清单合并。
- `categories.json` 目前没有消费方，准确性不影响运行，但不要留下失效键。
- 26.3 新增物品 271 个、新增方块 369 个，图标清单变长是预期行为。
- 村民与末影龙的模型、全部姿态常数是最大不确定项，以源码 diff 为准。
